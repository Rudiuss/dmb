# ДМБ Таймер · Bundeswehr

Приложение для iPhone, которое считает время до конца службы в Bundeswehr (Dienstzeitende).

## Возможности
- Поля для даты (и времени) начала и конца службы, плюс быстрые пресеты срока (FWD 7/17/23 мес., SaZ 2/4 года)
- Обратный отсчёт: дни / часы / минуты / секунды
- Процент отслуженного с точностью до 6 знаков после запятой
- 5 видов таймера: **кольцо**, **батарея**, **Maßband** (традиционная лента на 150 см), **песочные часы** и **сетка всех дней**
- Статистика: сколько осталось недель, выходных, будних дней, ночей, часов, минут и секунд
- Этапы: 25 %, Bergfest (50 %), 75 %, 150/100/30/7 дней до конца службы
- Конфетти в день окончания службы 🎉
- Работает без интернета, данные хранятся только на телефоне

## Установка на iPhone
1. Опубликуй репозиторий через GitHub Pages: *Settings → Pages → Deploy from a branch → выбери ветку и папку `/ (root)`*.
2. Открой ссылку `https://<username>.github.io/dmb/` в **Safari** на iPhone.
3. Нажми «Поделиться» → «На экран „Домой“».
4. Запусти «ДМБ» с домашнего экрана и введи свои даты.
